# Solenoid Latch Valve Home Assistant Integration

A custom Home Assistant integration for managing solenoid latch valves. This integration exposes valve controls, state monitoring, and automation-friendly entities for reliable control of latching solenoid valves.

## Features

- Control open/close actuation of solenoid latch valves
- Monitor valve state
- Support for multiple valves in a single installation

## Installation

1. Copy the custom integration folder into your Home Assistant `custom_components` directory.
2. Restart Home Assistant.
3. Configure the integration from the Home Assistant UI under `Settings > Devices & Services > Add Integration`.

## Configuration

This integration can be configured through the Home Assistant UI.

## Automations

Use the provided entities in automations to control valve behavior.

## Troubleshooting

- Ensure the integration folder is named `solenoid_latch_valve` inside `custom_components`.
- Restart Home Assistant after installation.
- Check Home Assistant logs for integration errors.
